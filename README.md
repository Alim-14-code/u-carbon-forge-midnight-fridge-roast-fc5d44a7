# Midnight Fridge Roast

One-line roast entry for make.fun's "Midnight Fridge Roast" bounty — a smart fridge refuses to open after midnight.

## Entry

> It's 12:03 and the fridge just told me it's 'off duty' — you're a box that keeps milk cold, not a nightclub bouncer.

## How to run

```sh
node main.ts
```

`main.ts` writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
